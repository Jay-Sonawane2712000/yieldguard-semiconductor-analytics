# Methods and limitations

YieldGuard maps SECOM label -1 to pass and 1 to failure, calls each row a production entity, and sorts by source timestamp with a deterministic row tie-break. The chronological split keeps 940 reference, 314 calibration, and 313 final entities. Data-quality and monitoring parameters are learned only from reference data. Candidate predictive models are fit on reference and selected on calibration. Association screening uses reference plus calibration. The final block is evaluated once after the champion and 10% review policy are committed.

Univariate monitoring uses reference-fitted I-MR and time-varying EWMA. Multivariate monitoring uses reference-median imputation, reference scaling, PCA retaining the configured explained variance, and empirical reference 99th-percentile T-squared and Q/SPE limits. Associations use Mann–Whitney U, Cliff’s delta, approximate outcome-stratified bootstrap intervals, and both BH and BY multiplicity control. Risk ranking compares a frozen histogram-gradient-boosting model with prevalence and fixed-monitoring baselines. PR-AUC is primary; ROC-AUC, Brier score, ECE, calibration bins, budget workload, precision, recall, and bootstrap intervals provide context.

Limitations are material. Measurements are anonymous and cannot support invented sensor meanings or mechanisms. The public data does not establish the exact physical entity, process cadence, specification limits, review cost, engineering capacity, or economic value. Failure counts are sparse, so ranking and policy estimates are unstable. Bootstrap intervals are approximate and do not preserve temporal dependence. Alerts identify statistical excursions, not failures or nonconformance. Associations and model importance do not establish causal root cause. The retrospective review queue is not validated for autonomous or production use. No simulation is implemented because defensible operating parameters are absent.
